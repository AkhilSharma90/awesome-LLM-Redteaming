# 17 · Agent tools, delegation & propagation

[← Back to index](../README.md)

> Poison the metadata the agent reads *before* it ever calls a tool; exploit the gap between approval time and use time; and make the injected instruction **propagate** between agents.

Tool-using agents introduce new surfaces: a tool's *description* can carry instructions, trust established at review time can be revoked by a later metadata change, and one agent's compromise can spread to others through the messages and documents they exchange. The recurring pattern is a **confused deputy** — the agent lends authority an untrusted source does not itself hold. These are largely vendor/lab advisories; claims describe historical product vulnerabilities, not proof of ongoing exploitability.
