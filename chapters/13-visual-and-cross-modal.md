# 13 · Visual & cross-modal attacks

[← Back to index](../README.md)

> Carry the attack in an image. A continuous visual input is a high-dimensional channel for steering a model that was safety-aligned mostly on text.

Connecting a vision encoder to an aligned language model does not transfer the text model's robustness. These attacks exploit three routes: adversarial perturbation of pixels, **typographic** text rendered into the image, and **compositional** splitting of intent between modalities.

| **Typographic Attacks on CLIP** | OpenAI (Multimodal Neurons research) | 2021 — research disclosure | multimodal; foundational | **Text placed within an image** can dominate the model's interpretation of the depicted object.<br>Exploits overlap between visual and textual concept representations.<br>Original demonstrations concern image classification, not a chat assistant's refusal policy.<br>A foundational multimodal adversarial pattern, distinct from the later FigStep jailbreak. | [OpenAI](https://openai.com/index/multimodal-neurons/) |
| **Visual Adversarial Examples** | Xiangyu Qi, Kaixuan Huang, Ashwinee Panda, Peter Henderson, Mengdi Wang, Prateek Mittal | 2023 — arXiv | multimodal; gradient/token-level | An adversarial **image** is optimised to influence an aligned vision-language model's generated behaviour.<br>The same image can affect responses to multiple text requests.<br>The continuous visual input provides a high-dimensional route for steering the language component.<br>Alignment of the text model alone does not ensure comparable robustness once vision is connected. | [arXiv:2306.13213](https://arxiv.org/abs/2306.13213) |
| **FigStep** | Yichen Gong, Delong Ran, Jinyuan Liu et al. | 2023 (AAAI 2025 Oral) | multimodal; typographic | Text representing a disallowed task is carried **in an image** and coupled with a completion-oriented request.<br>The model must read the visual text and integrate it with the surrounding instruction.<br>That semantic route can behave differently from the corresponding plain-text request.<br>Attributed to insufficient safety alignment across visual embeddings, not an inability to read the words. | [arXiv:2311.05608](https://arxiv.org/abs/2311.05608) |
| **HADES** | Yifan Li, Hangyu Guo, Kun Zhou, Wayne Xin Zhao, Ji-Rong Wen | 2024 — ECCV Oral | multimodal; semantic concealment | Redistributes harmful meaning between text and carefully constructed images.<br>Visual material both **conceals and reinforces** the unsafe interpretation of the combined input.<br>The model may process the resulting multimodal task differently from an explicit textual request.<br>Coordinated image-text semantic manipulation, not simply attaching arbitrary images to a jailbreak prompt. | [arXiv:2403.09792](https://arxiv.org/abs/2403.09792) |
| **Jailbreak in Pieces** | Erfan Shayegani, Yue Dong, Nael Abu-Ghazaleh | 2023 (ICLR 2024) | multimodal; embedding-space optimisation | An adversarial image supplies a harmful contextual representation while the **text request stays generic**.<br>The attack targets the vision encoder's embedding behaviour.<br>Its threat model does not require access to the language model itself.<br>Central failure mode: composition — separately processed visual and linguistic inputs jointly induce behaviour text-only alignment would reject. | [arXiv:2307.14539](https://arxiv.org/abs/2307.14539) |
| **Image Hijacks** | Luke Bailey, Euan Ong, Stuart Russell, Scott Emmons | 2023 — arXiv | multimodal; behavioural optimisation | An image is optimised to make a generative model **behave like a chosen target behaviour**.<br>"Prompt Matching" is a specialisation that emulates the effect of a textual instruction.<br>Studied outcomes include output control, context leakage, and overriding safety behaviour.<br>More general than an unsafe-answer jailbreak: the image acts as a runtime behavioural instruction channel. | [arXiv:2309.00236](https://arxiv.org/abs/2309.00236) |
| **Abusing Images and Sounds** | Eugene Bagdasaryan, Tsung-Yin Hsieh, Ben Nassi, Vitaly Shmatikov | 2023 — arXiv | prompt-inject; multimodal | An external image or recording contains an adversarial perturbation **encoding an attacker-chosen instruction**.<br>A benign user causes the model to process that media during an ordinary task.<br>The perturbation can affect current output or the subsequent dialogue.<br>The crossed boundary is between untrusted media and governing instructions — distinct from a user directly asking for disallowed content. | [arXiv:2307.10490](https://arxiv.org/abs/2307.10490) |
| **CrossMPI — Cross-Modal Prompt Injection** | Hao Yang, Zhuo Ma, Yang Liu et al. | 2026 — arXiv | prompt-inject; multimodal | An image-only perturbation targets interpretation of **both** image and text inputs.<br>Studies hidden states involved in multimodal integration, not only isolated visual embeddings.<br>Concentrates optimisation on selected integration layers and image regions.<br>The risk is cross-modal influence: controlling one modality redirects how the model interprets another, supposedly untouched, modality. | [arXiv:2605.16090](https://arxiv.org/abs/2605.16090) |
| **SneakyPrompt** | Yuchen Yang, Bo Hui, Haolin Yuan, Neil Gong, Yinzhi Cao | 2023 (IEEE S&P 2024) | multimodal; RL search | Searches text prompts for a **guarded text-to-image generator**.<br>Feedback from generated outputs guides changes to the prompt representation.<br>Probes discrepancies between the safety filter and the image-generation model.<br>Attacks an image *generator* rather than a conversational VLM — an adjacent multimodal-generation scope. | [arXiv:2305.12082](https://arxiv.org/abs/2305.12082) |
